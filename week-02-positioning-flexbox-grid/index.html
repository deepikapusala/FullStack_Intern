1. Float

CSS float is used to move an element to the left or right of its container. Other content can then flow around the floated element. This was commonly used for wrapping text around images before modern layout systems like Flexbox and Grid became popular. Try changing the image from float: left to float: right in the CSS and see how the paragraph moves around the image. The image can be floated to the left or right, and the text will automatically flow around the available space.
